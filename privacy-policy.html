Privacy Policy

How Focusea handles user-entered maritime data, preferences and advertising choices.

Focusea is a maritime decision-support workspace. The public website can use browser storage for preferences and can connect to the Focusea API for accounts, Deal Rooms, reports and approved document uploads when the production API is enabled.

Scope

This policy explains how Focusea handles information connected with maritime calculators, broker workflows, account forms, report history, advertising, contact requests and user-entered shipping content.

Information users may enter

Users may enter fixture terms, voyage estimates, laytime events, port information, cargo details, insurance quote inputs, account usernames, email addresses, reports and documents. Users must have authority to submit that material and should redact unnecessary personal, financial, legal, commercially sensitive or third-party confidential information.

Account and sign-up data

When the production API is enabled, Focusea stores a unique username, email address, salted password hash, account status, last-opened page and account timestamps on the server. Plain-text passwords are not stored. Authentication sessions and one-time password-reset tokens are stored only as cryptographic hashes and expire automatically. The browser may separately retain local demo workspace data and preferences.

Local storage

Focusea may use localStorage to remember appearance settings, report history, local account details, quiz progress and workflow state. This helps users return to the last workspace page. Clearing browser data may delete these records.

Cookies, consent and analytics

Focusea may use essential browser storage for site functionality and may use third-party cookies or identifiers if advertising is served. Non-essential tracking, analytics or advertising features should be controlled by consent tools where legally required.

Advertising and third parties

Focusea includes Google AdSense publisher metadata and ad code for review and future monetization. If Google serves ads, Google may process advertising identifiers, cookies, device data and consent choices according to Google's advertising policies and the consent message shown to visitors where required.

External links and data sources

Focusea links to maritime authorities, academic resources, news sources, GitHub and third-party services. Those websites have their own privacy practices. Source links, market labels and live/simulated badges are provided to help users understand where information comes from.

Retention and deletion

Browser-local records remain until the user clears site data or removes saved items. Server-side account, Deal Room, audit, report and document records remain while the service needs them for the requested workspace, security, integrity or legal obligations. Users may request access, correction or deletion through the contact page. Public GitHub issues remain under GitHub's own settings and policies.

Security

Focusea uses salted password hashing, expiring hashed sessions, rate limiting, file-type and size controls, access checks, audit records and security headers. No internet service can guarantee absolute security. Users must protect their email, password and devices and should promptly reset credentials after suspected compromise.

Children

Focusea is intended for maritime education and professional decision support. It is not designed for children to submit personal information.

User choices

Users can clear local browser data, avoid entering sensitive information, use privacy settings provided by the browser, manage advertising consent where available and contact Focusea through the contact page for privacy questions.

Policy updates

This policy may be updated as Focusea changes accounts, file uploads, document processing, analytics, advertising, licensed data integrations or paid services. Material changes will be dated on this page.

Contact

Privacy, product and security questions can be submitted through the contact page or the public GitHub issue tracker linked there.
